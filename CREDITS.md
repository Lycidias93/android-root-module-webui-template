## Attribution policy

The initial implementation is a clean integration rather than a verbatim fork of any one project. The upstream licenses are retained because the architecture and selected patterns were deliberately derived from those projects and future versions may vendor compatible MIT-licensed components.

When importing upstream code later:

1. Pin the exact commit.
2. Record each imported path in `UPSTREAMS.md`.
3. Preserve copyright headers.
4. Keep the matching license in `third_party/licenses/`.
5. Document local modifications.
